Accessibility Statement

Ponasa LLC wants this website to be usable by people with disabilities and by visitors using assistive technology.

Our approach

We aim for clear headings, readable contrast, keyboard-accessible controls, visible focus states, descriptive links, meaningful alternative text, and layouts that work across screen sizes and text zoom. The interactive map is supplemented by linked property profiles and a complete text-based property list in the site map.

Feedback and assistance

If you have difficulty using this website or need property information in another format, email info@ponasa.com or call +1 (954) 600-6579. Please include the page address, a description of the issue, and your preferred way to receive a response.

Ongoing work

Accessibility is an ongoing effort. We review reported barriers and make reasonable improvements as the website, browsers, and assistive technologies change.
